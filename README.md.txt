# Loan Approval Prediction — ML Classification Study

## Overview
End-to-end ML project predicting loan approval using 9 classifiers.

## Tech Stack
Python | scikit-learn | XGBoost | pandas | SMOTE | matplotlib | seaborn

## Key Highlights
- Compared 9 models: Logistic Regression to XGBoost
- Leak-free sklearn Pipeline with imputation, encoding, scaling
- SMOTE for class imbalance (training data only)
- Accuracy, F1, ROC-AUC evaluation
- 5-Fold Cross-Validation
- Feature importance (RF + XGBoost averaged)

## How to Run
1. Clone this repo
2. pip install -r requirements.txt
3. jupyter notebook Loan_Approval_Prediction.ipynb
